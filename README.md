# Мониторинг температуры: WPF + веб-панель

Учебный проект гибридного приложения для мониторинга температурных данных в реальном времени. WPF-клиент отправляет данные датчика температуры на ASP.NET Core сервер, а веб-панель отображает их в реальном времени.

## 📋 Описание проекта

**Цель работы:** Создать систему, в которой WPF-клиент отправляет данные температуры, а веб-приложение отображает их в реальном времени.

### Архитектура системы
- **WPF-клиент** (`TempWpf/`) — Десктопное приложение для отправки данных температуры
- **ASP.NET Core сервер** (`TemperatureServer/`) — Веб-сервер, получающий и обрабатывающий данные
- **Documents/** — Полная документация проекта

## 🔧 Технологический стек

- **Фреймворк:** 
  - WPF (Windows Presentation Foundation)

## 📨 Формат сообщений

Для обмена данными между WPF-клиентом и сервером используется **JSON**:

```json
{
  "temperature": 22.5,
  "timestamp": "2026-05-01T12:00:00"
}
```

### Описание полей

| Поле | Тип данных | Описание |
|------|-----------|---------|
| `temperature` | `double` | Значение температуры в градусах Цельсия |
| `timestamp` | `DateTime` | Дата и время отправки данных (ISO 8601) |

## 🚀 Инструкция по запуску

### Предварительные требования

- Visual Studio 2022
- .NET 6.0 или выше
- Современный веб-браузер

### 1. Запуск серверной части

1. Откройте проект ASP.NET Core в Visual Studio 2022
2. Установите необходимые зависимости (восстановление NuGet пакетов)
3. Запустите серверное приложение (F5)
4. Убедитесь, что сервер работает по адресу: **https://localhost:5001**

> **Примечание:** Порт по умолчанию — 5001. В случае конфликта портов проверьте конфигурацию в `appsettings.json`

### 2. Запуск веб-панели мониторинга

1. Откройте веб-браузер
2. Перейдите по адресу: **https://localhost:5001**
3. Должна открыться страница мониторинга температуры
4. Убедитесь, что соединение с сервером установлено

### 3. Запуск WPF-клиента

1. Откройте проект WPF в Visual Studio
2. Запустите приложение (F5)
3. В главном окне нажмите кнопку **«Старт»**
4. Проверьте, что данные температуры отображаются на веб-странице в реальном времени

## ✅ Проверка работоспособности

После запуска всех компонентов:

- ✓ WPF-приложение успешно отправляет данные
- ✓ Веб-панель получает и отображает температурные данные
- ✓ Данные обновляются в реальном времени
- ✓ История измерений сохраняется на сервере


## 🐛 Устранение неполадок

### Приложение не подключается к серверу
- Проверьте, запущен ли ASP.NET Core сервер на `https://localhost:5001`
- Убедитесь в правильности URL в конфигурации WPF-клиента
- Проверьте настройки брандмауэра

### Веб-панель не открывается
- Убедитесь, что сервер запущен
- Попробуйте очистить кэш браузера (Ctrl+Shift+Delete)
- Проверьте консоль браузера на наличие ошибок (F12)

### WPF-приложение вылетает при нажатии «Старт»
- Проверьте логи приложения
- Убедитесь, что все зависимости установлены
- Перестройте решение (Rebuild Solution)
